# docs

Reference docs for working in this repo. Each file is intentionally short. If
something is documented in code or `schema.graphql`, it is not duplicated here.

- [architecture.md](architecture.md) — components, data flow, where things live
- [design-decisions.md](design-decisions.md) — non-obvious choices and the why behind them
- [commands.md](commands.md) — dev, build, test, and admin/migration commands that actually exist today
- [glossary.md](glossary.md) — domain terms used everywhere in the schema and UI

If a doc is wrong, fix it in the same PR as the code change. Keep these terse.
